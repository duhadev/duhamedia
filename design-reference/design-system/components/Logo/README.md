# Logo

The lockup is the four-band disc mark followed by the wordmark, set in IBM Plex Sans 700.

- Primary: **duha media** in lowercase. Formal contexts: **DUHA MEDIA**.
- Mark file: Assets → Logos → `duha-mark.svg`. Size it at about 1.4× the wordmark's font size, with a `space-2` gap.
- The wordmark is `text`: ink on light grounds, white on dark sections. The mark keeps its four colors on every ground.
- Never stretch, recolor, outline, shadow, or animate the mark.
- The consumer provides the link target (usually `/`) and an accessible name ("Duha Media").
