Square-cornered CTA button; primary = the single accent element of a view.

```jsx
<Button variant="primary" href="/book">Book a Call</Button>
<Button variant="ghost">See the Work</Button>
```

Variants: primary (accent fill, light text), ghost (ink outline, fills on hover), ghost-light (for dark sections), dark (ink fill). Sizes sm/md/lg; 44px min height. Press state nudges down 1px.
