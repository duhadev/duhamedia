# S6-9 LinkStack (NEW block) fixtures

Block slug `linkStack`, one variant (no `variant` field). Socials and the capacity line come from the
`site-settings` / `scarcity` globals in the DB (dev DB currently has NO socials and NO `slots-line`
statement, so the showcase shows them only once those exist). The latest case study comes from the DB
(published only), or from the showcase-only `previewStudy` prop (not a field; ignored unless
`_status === 'published'`; use the registry's `fixtureStudies[0]`).

Shared link pieces (custom links so the fixture needs no DB pages):
```ts
const lsLinks = [
  { id: 'ls-work', icon: 'chart-line-up', link: { type: 'custom', url: '/work', label: 'The work', newTab: false } },
  { id: 'ls-clients', icon: 'quotes', link: { type: 'custom', url: '/testimonials', label: 'Clients', newTab: false } },
  { id: 'ls-news', icon: 'envelope-simple', link: { type: 'custom', url: '/newsletter', label: 'Newsletter', newTab: false } },
]
const lsBase = {
  identity: { showStudyMetric: true, fallbackLine: '[STRATEGIC PLACEHOLDER] Integrated ecommerce growth partner — Chicago' },
  primary: { link: { type: 'custom', url: '/book-a-call', label: 'Book a call', newTab: false }, capacity: 'slots-line' },
  showSocials: true,
  followLabel: 'Follow',
  siteLabel: 'On the site',
  links: lsLinks,
  latestCaseStudy: true,
  latestCaseStudyLabel: 'Case study',
  currentPush: { show: false, icon: 'file-text', link: { type: 'custom', url: '', label: '', newTab: false } },
}
```

1. Populated (published fixture study → metric + case-study link; current push on):
```ts
{ block: 'linkStack', variant: 'default', label: 'populated: latest published study metric + case-study link, socials, slots line, current push',
  data: { ...lsBase, previewStudy: fixtureStudies[0],
    currentPush: { show: true, icon: 'file-text', link: { type: 'custom', url: 'https://example.com/guide', label: '[Current push: the guide]', newTab: true } } } }
```
2. No-study fallback (launch state: fallbackLine, no case-study link):
```ts
{ block: 'linkStack', variant: 'default', label: 'fallback: no published case study (fallback line, no case-study link)',
  data: { ...lsBase } }
```
3. No socials (Follow section hidden):
```ts
{ block: 'linkStack', variant: 'default', label: 'no socials: Follow hidden',
  data: { ...lsBase, showSocials: false, previewStudy: fixtureStudies[0] } }
```
4. Slots statement missing (no capacity line; a missing `slots-line` row in the DB gives the same result and logs):
```ts
{ block: 'linkStack', variant: 'default', label: 'slots missing: no capacity line',
  data: { ...lsBase, primary: { ...lsBase.primary, capacity: 'none' }, previewStudy: fixtureStudies[0] } }
```
5. Minimal (nothing optional: identity + primary only):
```ts
{ block: 'linkStack', variant: 'default', label: 'minimal: identity + Book a call only',
  data: { ...lsBase, showSocials: false, links: [], latestCaseStudy: false, primary: { ...lsBase.primary, capacity: 'none' } } }
```
No `viewport` key: the block is one 480px column at every width (the design has desktop + mobile builds). Use `variant: 'default'` or the registry's key for single-variant blocks.
